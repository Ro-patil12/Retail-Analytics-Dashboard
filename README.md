# Retail-Analytics-Dashboard
This project presents a comprehensive Retail Analytics Dashboard built using Power BI. It provides insights into sales performance, product trends, customer behavior, returns, regional performance, and delivery efficiency.
Problem :
Retail businesses need a unified view to:
- Monitor sales and profitability  
- Analyze customer purchasing behavior  
- Identify high-performing products and regions  
- Track returns and delivery performance  

Key Metrics :
Total Sales:  $2.12M
Total Profit:  $263K  
Total Orders:  4,700  
Profit Margin:  12.43%  
Return Rate: 8.53%  
Avg Delivey Days: 4 Days
Total Products: 1862
Total Customer: 793

Report / Dashboard Features :
Executive Overview -
Monthly sales trend analysis  
Category-wise sales distribution (Technology, Furniture, Office Supplies)  
KPI cards for Sales, Profit, Orders, and Returns
Sale by State

Product Analysis - 
Top & bottom performing products  
Category-wise revenue contribution  
Profit vs discount analysis  

Customer Analysis -
Customer segmentation (Consumer, Corporate, Home Office)  
Top 10 customers by revenue  
New vs Repeat customer analysis  

Return Analysis -
Return orders trend over time  
Sales and loss due to returns  
Category and segment impact  

Regional Analysis -
Sales and profit by region (East, West, Central, South)  
Top cities by sales (New York, Los Angeles, etc.)  
Dealer-wise sales performance  

Delivery Analysis -
Average delivery time (4 days)  
Orders by ship mode (Standard, Second Class, First Class, Same Day)  
Order-level delivery insights  

Tools & Technologies Used :
- MYSQL
- Power BI 
- DAX (Data Analysis Expressions)  
- Data Modeling  
- Excel / CSV  

Key DAX Calculations :
- Total Sales & Profit  
- Profit Margin %  
- Return Rate %  
- Customer Segmentation (New vs Repeat)  
- Time Intelligence (Monthly Trends)  

Key Insights :
- Technology category contributes the highest sales (~36%)  
- Majority customers are repeat customers (~98%)  
- West and East regions generate the highest revenue  
- Returns impact overall profitability (~8.5% return rate)  
- Average delivery time is optimized at ~4 days
